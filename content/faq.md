## 提示 UID 或资格不符合

确认填写的是 Bilibili **数字 UID**，并确认舰长资格已生效。资格同步可能存在延迟，请稍后重试。

## 注册成功，但进入后无法登录

确认进服用户名与注册时完全一致。新版本在弹出的登录窗口输入密码；没有弹窗时使用 `/login 密码`。

## 提示密码错误或忘记密码

检查大小写和输入法。支持对话框的版本可点击“忘记密码？”；如果注册时未填写邮箱、页面没有恢复入口或恢复失败，请联系服务器管理员。

## 无法连接 windking.fans

确认使用 Java 版且地址没有多余空格，或尝试复制地址进入。

> 注：服务器只在主播开播档期内使用国内线路，学期内由凤凰城节点担当，部分地区可达性不保证，可使用加速器改善

## 我的版本能进入吗？

Java 版 1.7 及以上均可进入。Java 1.7–1.16.5 客户端存在世界高度、背包同步和声音映射限制；客户端版本低于服务器版本时，该客户端中不存在的物品、方块和机制不会完整显示。
