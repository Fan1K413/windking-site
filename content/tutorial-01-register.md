先确认下面四项已经准备好，再在本页完成账号注册。

## 注册前须知

- **已录入的舰长 UID**：上舰后由主播手动录入名单；录入后即使舰长到期仍可进入。
- **B 站 UID**：打开自己的 B 站个人主页即可查看，是一串数字。
- **Java 版游戏用户名**：填写你实际进入服务器时使用的用户名，务必保持一致。
- **单独设置的登录密码**：用于舰长服登录，不要使用微软账号或 B 站账号密码。

## 填写注册信息

点击“立即注册”后按下表填写。注册前需由主播将舰长 UID 录入名单；如果无法提交，可前往独立注册页完成注册。

| 页面字段 | 应该填写什么 |
| --- | --- |
| 游戏用户名 | 你的 Minecraft Java 版用户名，必须和进服时一致。 |
| 密码 | 为舰长服单独设置的新密码，之后在游戏内登录会用到。 |
| 确认密码 | 再次输入上面的舰长服密码，两次必须完全一致。 |
| B站 UID | 当前舰长账号的数字 UID，用于验证舰长身份。 |
| 邮箱（可选） | 建议填写常用邮箱，忘记密码时可用于恢复。 |

> **密码安全提醒：**这里只设置舰长服密码。不要填写你的微软、Minecraft 或 B 站账号密码。

1. 检查游戏用户名、B 站 UID 和两次密码。
2. 点击注册按钮，等待页面提示注册结果。
3. 注册成功后记住这组“游戏用户名 + 舰长服密码”。
