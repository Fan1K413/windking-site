注册前，请准备你的 **Bilibili 数字 UID**、Minecraft Java 用户名，以及一个只用于本服务器的密码。

## 注册前须知

- 请填写 Bilibili **数字 UID**，不要填写昵称或个人空间链接。
- Minecraft 用户名将用于进入服务器。
- 请不要复用 Bilibili、邮箱或其他重要账号的密码。

## 填写注册表单

| 字段 | 说明 |
| --- | --- |
| Minecraft 用户名 | 进入服务器时使用的游戏名。 |
| Bilibili UID | 纯数字 UID，用于资格验证。 |
| 密码 | 专用于服务器的登录密码。 |
| 邮箱 | 可选；建议填写，便于后续协助。 |

点击页面上方的“立即注册”打开表单。注册成功后，请继续完成安装并在游戏内登录。

> 请勿在公开频道、截图或邮件中发送密码。
