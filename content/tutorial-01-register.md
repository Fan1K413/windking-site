先确认下面四项已经准备好，再在本页完成账号注册。

## 注册前须知

- **已录入的舰长 UID**：上舰后由主播手动录入名单；录入后即可使用。
- **B 站 UID**：打开自己的 B 站个人主页即可查看，是一串数字。
- **Java 版游戏用户名**：填写你实际进入服务器时使用的用户名，务必保持一致。
- **单独设置的登录密码**：用于舰长服登录，不要使用微信、B 站账号密码。

## 填写注册表单

| 字段 | 说明 |
| --- | --- |
| Minecraft 用户名 | 填写你实际进入服务器时使用的游戏名。 |
| Bilibili UID | 纯数字 UID，用于资格验证。 |
| 密码 | 请设置仅用于舰长服的登录密码。 |
| 邮箱 | 可选；建议填写，便于后续协助。 |

点击上方“立即注册”打开表单并提交。注册成功后，请继续完成安装，并在游戏内使用密码登录。

> 请勿在公开频道、截图或邮件中发送密码；管理员不会主动索取你的密码。
